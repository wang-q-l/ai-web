# 审计文书智能撰写系统使用指南

## 系统简介

审计文书智能撰写系统是一个基于 AI 技术的智能文书生成工具，支持审计全流程中六种核心文书的智能撰写。系统通过理解文书间的关联关系，自动提取前置文书数据，结合 AI 生成能力，帮助审计人员快速、准确地完成文书撰写工作。

### 核心特性

- **统一 AI 助手框架**：一套框架支持所有文书类型的智能生成
- **文书关联管理**：自动识别和提取前置文书数据，减少重复录入
- **混合生成模式**：结合自动生成、对话生成和智能推荐，灵活适应不同场景
- **法规智能检索**：支持法规条款匹配和全网搜索，快速找到定性依据
- **模板配置系统**：基础模板 + 自定义模板，满足个性化需求
- **质量智能检查**：自动检查内容完整性、规范性和一致性

## 支持的文书类型

系统支持审计全流程的六种核心文书，按照审计工作流程依次为：

### 1. 审计通知书

**作用**：审计工作的起始文书，通知被审计单位审计事项。

**主要章节**：

- 通知对象
- 审计目的
- 审计范围
- 审计时间
- 审计组成员

**生成模式**：对话式生成（需要用户提供项目信息）

**前置依赖**：无（首个文书）

### 2. 审计方案

**作用**：明确审计目标、重点关注事项和审计程序。

**主要章节**：

- 审计目标
- 重点关注事项
- 风险关注
- 审计程序与方法
- 时间安排

**生成模式**：混合生成（自动提取审计通知书信息 + 对话补充）

**前置依赖**：审计通知书（项目信息、审计组）

### 3. 审计取证单

**作用**：记录审计过程中的取证活动和要求。

**主要章节**：

- 审计事项摘要
- 风险点描述
- 审计程序
- 预期结果
- 取证要求

**生成模式**：混合生成（自动提取前置数据 + 对话补充）

**前置依赖**（多数据源）：

1. **问题清单**：提取已发现的问题作为审计事项
2. **审计方案**：提取审计事项、重点关注事项和审计程序

**数据来源说明**：

- 系统会同时检索问题清单和审计方案
- 优先使用问题清单中的具体问题
- 从审计方案中补充审计程序和方法
- 用户可以选择使用哪些数据源

### 4. 审计底稿

**作用**：详细记录审计过程、发现和证据。

**主要章节**：

- 审计过程
- 审计发现
- 证据清单
- 初步结论
- 定性依据

**生成模式**：混合生成（自动汇总前置数据 + 补充说明）

**前置依赖**（多数据源）：

1. **问题清单**：提取问题描述和初步分析
2. **审计事项**：提取审计事项的详细信息
3. **审计取证单**：提取取证内容和审计程序执行情况

**数据来源说明**：

- 系统会综合问题清单、审计事项和审计取证单的数据
- 问题清单提供问题的基本描述
- 审计事项提供事项的详细背景
- 审计取证单提供取证过程和证据材料
- 用户可以选择使用哪些数据源进行汇总

### 5. 审计报告

**作用**：正式的审计结论和建议文书。

**主要章节**：

- 审计概况
- 审计发现
- 审计结论
- 审计建议

**生成模式**：混合生成（自动汇总审计底稿 + 优化润色）

**前置依赖**：审计底稿（审计发现、证据）

### 6. 审计意见书

**作用**：对被审计单位提出整改要求和后续跟踪安排。

**主要章节**：

- 审计意见
- 整改要求
- 整改期限
- 后续跟踪

**生成模式**：混合生成（提取审计报告结论 + 补充要求）

**前置依赖**：审计报告（审计结论、建议）

## 文书关联关系

```
审计通知书
    ↓ (项目基本信息)
审计方案
    ↓ (重点关注事项、风险点、审计程序)
审计取证单
    ↓ (审计事项摘要、取证内容)
审计底稿
    ↓ (审计发现、证据汇总)
审计报告
    ↓ (审计结论、建议)
审计意见书
```

## 使用流程

### 基本使用流程

1. **打开 AI 助手**
   - 在文书编辑页面点击"AI 助手"按钮
   - 系统自动识别当前文书类型
   - 加载对应的章节配置

2. **查看关联文书**
   - 系统自动推荐可用的前置文书
   - 查看数据预览，确认数据质量
   - 选择或调整关联文书

3. **生成文书内容**
   - **自动生成**：有充足前置数据时，直接生成
   - **对话生成**：AI 提问，用户回答，收集完整后生成
   - **混合生成**：基于前置数据生成初稿，通过对话补充完善

4. **预览和调整**
   - 查看生成的内容
   - 可以重新生成或手动编辑
   - 确认后插入到编辑器

5. **保存文书**
   - 内容插入编辑器后可继续编辑
   - 保存草稿或正式提交

### 批量生成

对于有充足前置数据的文书，可以使用"一键生成全部"功能：

1. 点击"一键生成全部"按钮
2. 系统按章节顺序依次生成
3. 显示生成进度
4. 统一预览所有章节
5. 确认后批量插入

## 法规智能检索

### 使用场景

在撰写审计底稿的"定性依据"章节时，需要引用相关法律法规条款。系统提供两种检索方式：

### 方式一：从提供的法规中匹配条款

**适用场景**：已有法规文本，需要找到最相关的条款。

**使用步骤**：

1. 在法规检索面板选择"我已有法规文本"
2. 输入或粘贴法规内容
3. 输入问题描述（审计发现的问题）
4. 点击"智能匹配"
5. 系统分析法规内容，匹配最相关的条款
6. 查看匹配结果（Top 3-5 条，带相关度评分）
7. 选择合适的条款插入文书

**示例**：

```
问题描述：发现某单位未按规定进行政府采购招标
法规文本：《政府采购法》全文
匹配结果：
  ✓ 《政府采购法》第三十条 (相关度: 95%)
    "采购人需要执行政府采购政策的，应当在采购文件中明确..."
  ✓ 《政府采购法》第七十一条 (相关度: 88%)
    "采购人、采购代理机构有下列情形之一的..."
```

### 方式二：全网搜索相关法规

**适用场景**：不确定适用哪些法规，需要系统帮助查找。

**使用步骤**：

1. 在法规检索面板选择"全网搜索法规"
2. 输入问题描述（审计发现的问题）
3. 点击"智能搜索"
4. 系统搜索相关法律法规
5. AI 评估法规适用性
6. 从筛选后的法规中匹配具体条款
7. 查看推荐结果（带置信度）
8. 选择合适的法规和条款插入文书

**示例**：

```
问题描述：发现某单位固定资产管理混乱，账实不符
搜索结果：
  ✓ 《行政事业单位资产管理办法》(置信度: 92%)
    第十五条："行政事业单位应当建立健全资产管理制度..."
  ✓ 《政府会计准则第3号——固定资产》(置信度: 85%)
    第八条："固定资产应当按照成本进行初始计量..."
```

### 检索结果说明

**相关度评分**：0-100%，表示条款与问题的相关程度

- 90% 以上：高度相关，建议直接使用
- 70%-90%：较为相关，可以参考
- 70% 以下：相关性较低，建议重新搜索

**置信度**：0-100%，表示法规适用性的可信程度

- 90% 以上：高度可信，建议使用
- 70%-90%：较为可信，需要人工确认
- 70% 以下：可信度较低，建议谨慎使用

## 生成模式详解

### 自动生成模式

**特点**：

- 无需用户输入
- 基于前置文书数据自动生成
- 生成速度快

**适用场景**：

- 有充足的前置数据
- 章节内容相对标准化
- 需要快速生成初稿

**示例**：

- 审计报告的"审计概况"章节（从审计通知书和审计方案提取）
- 审计意见书的"审计意见"章节（从审计报告提取）

### 对话生成模式

**特点**：

- AI 主动提问
- 用户逐步回答
- 收集完整信息后生成

**适用场景**：

- 缺少前置数据
- 需要用户提供特定信息
- 首个文书（如审计通知书）

**示例**：

- 审计通知书的"审计目的"章节
- 审计方案的"时间安排"章节

**对话流程**：

```
AI: 请问本次审计的主要目的是什么？
用户: 检查财务管理制度执行情况
AI: 审计范围包括哪些方面？
用户: 2023年度全部财务收支
AI: 预计审计时间是？
用户: 2024年1月15日至2月15日
AI: 好的，正在生成审计通知书...
```

### 混合生成模式

**特点**：

- 结合自动生成和对话生成
- 先基于前置数据生成初稿
- 再通过对话补充完善

**适用场景**：

- 有部分前置数据
- 需要用户补充特定信息
- 大多数文书的常见场景

**示例**：

- 审计取证单的"审计事项摘要"（从审计方案提取 + 用户补充）
- 审计底稿的"审计发现"（从取证单提取 + 用户补充证据）

**生成流程**：

```
1. 系统提取前置数据生成初稿
2. 展示初稿给用户
3. AI 提问补充缺失信息
4. 用户回答
5. AI 整合生成最终内容
```

## 最佳实践

### 1. 按顺序撰写文书

建议按照审计工作流程顺序撰写文书：

```
审计通知书 → 审计方案 → 审计取证单 → 审计底稿 → 审计报告 → 审计意见书
```

这样可以最大化利用文书关联功能，减少重复录入。

### 2. 及时保存前置文书

在撰写下一份文书前，确保前置文书已保存。系统只能提取已保存的文书数据。

### 3. 检查关联数据质量

在生成前，查看系统推荐的关联文书，确认数据质量：

- 数据是否完整
- 内容是否准确
- 是否是最新版本

### 4. 合理使用生成模式

- **首次生成**：使用混合模式，确保内容完整
- **快速迭代**：使用自动模式，快速生成多个版本
- **精细调整**：使用对话模式，逐步完善细节

### 5. 善用法规检索

- **已知法规**：使用条款匹配，快速定位
- **不确定法规**：使用全网搜索，发现适用法规
- **多次搜索**：尝试不同的问题描述，获得更好的结果

### 6. 人工审核必不可少

AI 生成的内容仅供参考，必须经过人工审核：

- 检查事实准确性
- 确认法规适用性
- 调整语言表达
- 补充专业判断

### 7. 建立自定义模板

对于经常使用的文书格式，可以创建自定义模板：

- 保存常用的章节结构
- 预设常用的表述方式
- 提高生成质量和效率

## 常见问题

### Q1: 为什么系统没有推荐关联文书？

**可能原因**：

- 前置文书尚未保存
- 前置文书数据不完整
- 当前文书类型不依赖前置文书（如审计通知书）

**解决方法**：

- 检查前置文书是否已保存
- 补充前置文书的必填章节
- 使用对话模式手动输入信息

### Q2: 生成的内容不符合预期怎么办？

**解决方法**：

- 点击"重新生成"尝试再次生成
- 调整关联文书的选择
- 在对话中提供更详细的信息
- 使用编辑器手动修改生成的内容

### Q3: 法规检索找不到相关结果？

**解决方法**：

- 调整问题描述，使用更准确的关键词
- 尝试不同的搜索方式（条款匹配 vs 全网搜索）
- 手动输入已知的法规名称
- 咨询法律专业人员

### Q4: 可以同时生成多个章节吗？

**回答**：可以。使用"一键生成全部"功能可以批量生成所有章节。但建议：

- 首次使用时逐章节生成，确保质量
- 熟悉系统后使用批量生成提高效率
- 批量生成后仍需逐章节审核

### Q5: 生成的内容可以保存为模板吗？

**回答**：可以。系统支持自定义模板功能：

- 在生成满意的内容后，点击"保存为模板"
- 为模板命名并选择适用范围
- 下次生成时可以选择使用自定义模板

### Q6: 系统支持哪些文书格式？

**回答**：系统生成的内容为富文本格式（HTML），可以：

- 直接在编辑器中编辑
- 导出为 Word 文档
- 导出为 PDF 文档
- 复制到其他应用程序
