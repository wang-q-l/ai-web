# 审计项目推荐AI助手 - 弹窗交互方案设计

## 设计目标

将推荐列表从对话框中移出，通过弹窗方式展示，提供更清晰的交互体验。

## 交互流程

### 1. AI思考过程

- 用户发送问题后，AI在对话框中显示思考过程
- 思考步骤逐步展示（带动画）
- 思考完成后，思考过程保留在对话框中

### 2. 推荐结果展示

- 思考完成后，**自动弹出推荐列表弹窗**
- 弹窗标题：审计项目推荐清单
- 弹窗内容：
  - 统计信息（共X个项目，P0/P1/P2/P3分布）
  - 推荐列表表格（带复选框）
  - 操作按钮（全部列入计划、选择部分列入计划）

### 3. 对话框中的提示

- 思考过程最后一步改为：
  ```
  ✅ 给您推荐了一个建议立项的被审计单位清单，已为您打开推荐列表
  ```
- 不再显示"详细推荐列表如下："
- 不在对话框中显示表格

### 4. 查看历史推荐

- 在页面右上角添加"查看推荐列表"按钮
- 点击按钮可以随时打开最近一次的推荐列表弹窗
- 如果没有推荐记录，提示"暂无推荐记录"

## 技术实现

### 1. 组件结构

```
index.vue (主页面)
├── 对话区域
│   ├── 欢迎消息
│   ├── 消息列表
│   └── 输入框
├── 推荐列表弹窗 (el-dialog)
│   ├── 统计信息
│   ├── 推荐表格 (带复选框)
│   └── 操作按钮
└── 查看推荐按钮 (右上角)
```

### 2. 数据管理

```typescript
// 当前推荐列表
const currentRecommendations = ref<RecommendationItem[]>([])

// 弹窗显示状态
const dialogVisible = ref(false)

// 选中的推荐项
const selectedRecommendations = ref<RecommendationItem[]>([])
```

### 3. 交互逻辑

1. AI返回推荐结果后：
   - 保存到 `currentRecommendations`
   - 设置 `dialogVisible = true`
   - 自动打开弹窗

2. 用户点击"查看推荐列表"按钮：
   - 检查 `currentRecommendations` 是否为空
   - 不为空则设置 `dialogVisible = true`
   - 为空则提示"暂无推荐记录"

3. 用户操作推荐列表：
   - 勾选项目
   - 点击"全部列入计划"或"选择部分列入计划"
   - 确认后关闭弹窗

## UI设计

### 弹窗样式

- 宽度：80%
- 最大宽度：1400px
- 高度：自适应，最大80vh
- 表格最大高度：500px（内部滚动）

### 查看推荐按钮

- 位置：页面右上角
- 样式：主题色按钮，带图标
- 图标：列表图标
- 文字：查看推荐列表

## 优势

1. **对话框更简洁**：只显示思考过程和文字回复，不被大表格占据
2. **推荐列表更突出**：弹窗方式更能吸引用户注意
3. **操作更方便**：弹窗中的操作按钮更容易找到
4. **可重复查看**：通过"查看推荐列表"按钮随时查看
5. **更好的空间利用**：弹窗可以更宽，表格显示更完整
