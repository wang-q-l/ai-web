## 一、需求概述

在审计取证单编辑页面增加AI撰写功能，帮助用户快速生成规范的取证单内容。

### 核心需求

- 侧边抽屉方式触发AI助手
- 对话式交互收集信息
- 结构化内容生成（按章节）
- 支持分段插入或全部插入
- 自动带入项目上下文信息

## 二、方案选择

**最终方案**：智能表单 + 按需生成（方案D）

结合了方案B（一次性对话 + 批量生成）和方案C（智能推荐 + 按需生成）的优点：

- AI智能分析上下文，预填充部分问题
- 用户可选择性回答和生成章节
- 支持快速生成全部或逐个生成
- 灵活的插入方式

## 四、AI助手抽屉设计

### 4.1 布局结构（600px宽）

```
┌─────────────────────────────────────┐
│ 🤖 AI 助手                    [×]   │ ← 标题栏
├─────────────────────────────────────┤
│ 📊 项目上下文 [▼]                   │ ← 可折叠卡片
├─────────────────────────────────────┤
│ 📋 章节生成                         │ ← 章节列表区
│ ✅ 审计事项概要        [生成]      │
│ ⚠️ 审计程序 (需补充2个问题) [生成] │
├─────────────────────────────────────┤
│ 📄 已生成内容 (2/6)                 │ ← 已生成内容区
├─────────────────────────────────────┤
│ [全部插入] [保存草稿] [清空]        │ ← 底部操作栏
└─────────────────────────────────────┘
```

### 4.2 章节状态

- **✅ 可直接生成**：AI已从上下文提取足够信息
- **⚠️ 需补充信息**：需要用户回答问题
- **○ 可选章节**：非必填章节
- **✓ 已生成**：章节已生成完成

### 4.3 标准章节列表

1. 审计事项概要
2. 风险点描述
3. 审计程序
4. 预期结果
5. 取证要求
6. 其他说明（可选）

## 五、交互流程

### 5.1 打开AI助手

1. 点击"AI助手"按钮
2. 抽屉从右侧滑入
3. 智能分析项目信息（300ms）
4. 显示章节生成状态

### 5.2 快速生成（可直接生成的章节）

1. 点击章节的"生成"按钮
2. 调用AI API生成内容
3. 显示在"已生成内容"区域
4. 提供编辑、重新生成、插入操作

### 5.3 对话式生成（需补充信息的章节）

1. 点击章节的"生成"按钮
2. 展开对话区域
3. AI逐个提问，用户回答
4. 所有问题回答完成后生成内容

### 5.4 一键生成全部

1. 点击"一键生成全部章节"按钮
2. 选择生成方式：
   - 快速生成（AI自动推断）
   - 完整生成（逐个回答问题）
3. 批量生成所有章节

### 5.5 插入内容

- **单个插入**：选择插入方式（光标位置/替换全部/追加到末尾）
- **批量插入**：按顺序插入所有已生成章节
