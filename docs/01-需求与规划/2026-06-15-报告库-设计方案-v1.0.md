# 报告库设计方案

## 一、项目概述

在「项目管理」一级菜单下新增二级模块「报告库」，作为审计报告的集中管理与复用中心。整体功能范式对标已上线的「管理建议库」——左侧分类目录 + 右侧内容列表 + 批量引入，但展示形态从表格改为**卡片**，内容从文本建议改为**上传的报告文件**，并新增**收藏**与**在线预览**能力。

报告库与建议库是同一父菜单（项目管理 / `audit.ts`）下的兄弟二级菜单。

**核心价值：**

- 集中沉淀各项目的审计报告，按项目类型分类归档，便于检索与复用
- 支持收藏常用报告、在线预览，提升报告查阅效率
- 可从项目列表批量引入项目已有的报告附件，减少重复上传

## 二、功能范围

| 区域 | 功能 |
| --- | --- |
| 左侧分类目录 | 预置 5 个项目类型分类（财务审计/合规审计/绩效审计/专项审计/其他）+ 用户自建分类；树形多级；新增/重命名/删除子分类；按分类筛选 |
| 右侧报告列表 | 卡片展示（报告名称、报告分类、创建日期）；搜索、排序、收藏筛选、分页 |
| 报告操作 | 新增、编辑、删除、收藏（星标切换）、在线预览 |
| 批量引入 | 从项目列表引入项目已有的报告附件（大弹窗，2 步：选项目报告 → 预览确认） |

## 三、核心模块设计

### 3.1 左侧分类目录

- 复用建议库的扁平存储 + 递归建树范式（`parentId` 结构，计算 `selfCount`/`totalCount`）
- 顶部「全部报告」虚拟根节点；初始化时系统预置 5 个项目类型分类 + 1 个「未分类」兜底
- 预置分类与自建分类并存，均可在其下新增子分类
- 删除有防护：含子分类或含报告时禁止删除；预置项目类型分类与「未分类」不可删
- hover 显示操作图标：新增子分类、重命名、删除

### 3.2 右侧报告卡片列表

- 卡片网格布局（响应式，一行多张），每张卡片显示：
  - 报告名称（标题，可点击预览）
  - 报告分类（标签）
  - 创建日期
  - 右上角星标（收藏切换）
  - 底部操作：预览、编辑、删除
- 工具栏：面包屑（当前分类）+ 搜索框（按报告名称模糊匹配）+ 排序（创建日期/名称）+「只看收藏」开关 +「从项目引入」「新增报告」按钮
- 分页器（10/20/50）

### 3.3 新增/编辑报告弹窗

- 字段：报告名称、报告分类（分类树选择）、文件上传（PDF/Word/Excel 等）
- 创建日期由系统自动生成；编辑时回显，可替换文件

### 3.4 在线预览

- PDF：`el-dialog` 内嵌 `iframe` 预览（mock 阶段用占位/文件 URL）
- 非 PDF（Word/Excel）：降级为「下载 / 新窗口打开」提示
- 与法规全文预览思路一致：mock 阶段简化，真实环境接文件 URL

### 3.5 从项目列表引入（大弹窗，2 步）

- 对标建议库的 import 弹窗范式
- 第一步：左项目树（年份→项目）+ 右项目报告附件列表，跨项目勾选累加；已引入过的报告（按文件名+URL 查重）不可选，标「已引入」
- 第二步：预览确认 + 统一/逐条指定目标分类（默认按项目类型自动分发到同名分类）
- 提交后关闭弹窗，列表刷新 + 悬浮提示

## 四、数据结构与流向

### 4.1 类型定义（`types/report-library.ts`）

| 类型 | 关键字段 |
| --- | --- |
| `ReportCategory` | `id`、`name`、`parentId`、`sortOrder?` |
| `ReportCategoryNode` | 继承 Category + `children?`、`selfCount?`、`totalCount?` |
| `Report` | `id`、`name`（报告名称）、`categoryId`、`fileName`、`fileUrl`、`fileType`、`fileSize`、`isFavorite`、`createdAt`、`updatedAt`、`sourceProjectId?`（引入来源） |
| `ReportListQuery` | `categoryId?`、`keyword?`、`sortBy`（'createdAt'\|'name'）、`onlyFavorite?`、`page`、`pageSize` |
| `AuditProjectNode` | `id`、`name`、`type`（'year'\|'project'）、`children?`（引入用，复用建议库） |
| `ProjectReportAttachment` | `projectId`、`projectName`、`name`、`fileName`、`fileUrl`、`fileType`、`fileSize`、`category`（项目报告附件） |
| `ReportImportPreviewItem` | `tempId`、`projectId`、`reportName`、`projectCategory`、`fileName`、`fileUrl`、`fileType`、`status`、`targetCategoryId` |
| `ImportResult` | `success`、`skipped`、`failed` |

### 4.2 API（`api/report-library.ts`） + Mock（`mock/report-library.ts`）

- **分类**：`getCategoryTree` / `addCategory` / `updateCategory` / `deleteCategory`
- **报告**：`getReportList` / `addReport` / `updateReport` / `deleteReport` / `toggleFavorite`
- **引入**：`getAuditProjectTree` / `getProjectReports(projectId)` / `checkImportDuplicate` / `importFromProjects`

### 4.3 数据流向

- 新增/编辑/引入 → 写入 mock 模块级 `reports[]` → `getReportList` 分页筛选返回
- 收藏切换 → `toggleFavorite` 改 `isFavorite` → 列表/「只看收藏」即时反映
- 分类操作 → 改 mock `categories[]` → 重建树 + 重算 `selfCount`/`totalCount`
- 引入查重 → `checkImportDuplicate` 按文件名 + URL 严格匹配库内已有

## 五、边界情况处理

- **分类删除防护**：含子分类或含报告时禁止删除并提示；预置项目类型分类与「未分类」不可删（避免破坏同步逻辑）
- **引入查重**：按文件名 + URL 严格匹配库内已有，第一步即禁选并标「已引入」；同批次重复只保留第一条
- **预览降级**：非 PDF 文件无法内嵌时，提供「下载 / 新窗口打开」
- **文件上传约束**：限制类型（pdf/doc/docx/xls/xlsx）与单文件大小（与项目现有附件约束一致，如 ≤10MB）
- **空态**：分类下无报告时卡片区显示空态提示
- **多条件叠加**：「只看收藏」与当前选中分类、搜索关键词三者可同时生效
